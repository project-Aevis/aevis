The Aevis Dock

Fast, interactive, and unobtrusive. The Aevis Dock manages running windows and pinned shortcuts with precision.

  • Smart Window Previews: Hover over any active app to view high-resolution live thumbnails powered by Plasma Window Management protocol.
  • Intelligent Auto-Hide: Smoothly clears screen space when windows maximize or overlap the dock area.
  • Active Indicators & Badging: Flat subtle indicators show active instances, notification badges, and background tasks.
  • Context Menus & Actions: Right-click to pin, unpin, launch new windows, or access app specific shortcuts directly.

Native Media

HyperTube Music Player

A truly native C++20 and Qt Quick YouTube Music client built specifically for Linux. Zero Electron, zero browser bloat.

  • Pure Native Speed: Extremely lightweight startup and low memory usage compared to web-wrapper players.
  • Full YouTube Music & Local Support: Explore charts, search with filters, edit playlists, and upload or play local FLAC/MP3 files.
  • Audio Perfection: Smart transitions with gapless playback, crossfade, beat-aware tempo matching, and built-in Equalizer.
  • Timed Lyrics & Video Switch: Toggle seamlessly between audio track and full music video, or view real-time synced lyrics.
  • Smart Offline Mode: Download tracks automatically for offline listening when network connection is absent.

Build & Install Aevis OS

Install components directly or run our quick build script.

Terminal Command 
# Clone and build entire Aevis OS desktop suite
git clone https://github.com/cutefishos/aevis.git
cd aevis

# Run local installation script
./local-install.sh
Debian/Ubuntu Prerequisites & Build 
# Install dependencies
sudo apt install cmake extra-cmake-modules pkg-config build-essential \
    qt6-base-dev qt6-declarative-dev qt6-tools-dev kwayland-dev

# Build Shell (Status bar, Dock, Launcher)
mkdir build && cd build
cmake -DCMAKE_INSTALL_PREFIX:PATH=/usr ..
make -j$(nproc)
sudo make install
Build HyperTube Music Client 
# Build HyperTube C++20 / Qt Quick app
cd app
mkdir build && cd build
cmake -DCMAKE_BUILD_TYPE=Release ..
make -j$(nproc)
./hypertube
