Project Aevis • Qt 6 / C++20 / Wayland Desktop

Pure, Purposeful Desktop Simplicity.

A modern, fast, and elegant Linux desktop environment built on Qt 6, C++20, and KDE Frameworks 6. Engineered for low system overhead, fluid responsiveness, and native desktop integration.

Get Started Explore Organization

Designed for Focus & Performance

Aevis OS combines native C++ performance with modern declarative Qt Quick interfaces.

Native C++20 & Qt 6

Built with modern C++20 standards and Qt 6.8 for minimal CPU and memory usage with instant application launch times.

FishUI Control Library

Clean, responsive QML component library featuring light styling, rounded corners, crisp icons, and fluid animations.

Unified Shell Engine

A fast desktop shell combining status bar, dock, launcher, and desktop wallpaper engine in a single process.

KWin 6 / Wayland Native

Seamless window management on Wayland with custom window decorations, switcher layouts, and rounded window corner effects.

Modular App Suite

Dedicated native applications for File Management, System Settings, Task Manager, Terminal, Photos, and Calculator.

HyperTube Music

Fully native YouTube Music client built with C++20 and Qt Quick, delivering zero Electron runtime overhead.

Building & Installation

Project Aevis includes automated build scripts to compile and install all components from source.

1

Install Build Dependencies

Install Qt 6, CMake, C++ compiler, and KDE Frameworks 6 development packages:

sudo apt update
sudo apt install -y build-essential cmake pkg-config extra-cmake-modules \
    qt6-base-dev qt6-declarative-dev qt6-tools-dev \
    libkf6coreaddons-dev libkf6windowsystem-dev libkf6networkmanagerqt-dev \
    libkf6bluezqt-dev libkf6kio-dev libkdecorations3-dev kwin-dev
2

Clone Workspace Meta-Repository

Clone the root repository recursively to fetch all 26 component submodules:

git clone --recursive https://github.com/project-Aevis/aevis.git
cd aevis
3

Run Automated Installer

Execute the automated fetch and build script for system-wide or user-local installation:

# System-wide installation to /usr
sudo ./install.sh

# Or user-local installation
./local-install.sh
